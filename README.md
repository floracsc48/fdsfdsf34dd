# Голосовой ассистент "Гостлик"

Скрипт `voice_assistant.py` реализует простого офлайн-ассистента,
который реагирует только на заданные активационные слова ("гостлик",
"горилка", "горилла" и 47 созвучных вариантов), а затем записывает и
выводит сказанную фразу до тех пор, пока в эфире не наступит тишина.

## Возможности

- Ожидание одного из 50 активационных слов и игнорирование остальных.
- Немедленный вывод распознанного текста после активации.
- Автоматическое завершение записи после 5 секунд тишины (при этом
  выдерживается дополнительная пауза 3 секунды для возможного
  продолжения фразы).
- Цветовое выделение: списки слушаемых слов выводятся зелёным цветом,
  игнорируемые примеры — красным. Финальный текст сессии также
  подсвечивается зелёным.
- Аудио-сигналы начала и завершения записи для обратной связи.
- Офлайн-распознавание речи на базе [Vosk](https://alphacephei.com/vosk/).

## Установка

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Затем скачайте и распакуйте русскую модель Vosk, например
`vosk-model-small-ru-0.22`, и укажите путь к каталогу модели:

```bash
mkdir -p models
cd models
wget https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip vosk-model-small-ru-0.22.zip
cd ..
# либо экспортируйте переменную окружения, если модель лежит в другом месте
export VOSK_MODEL_PATH=/path/to/vosk-model-small-ru-0.22
```

> **ESP32 Wroom-32.** Для переноса логики на микроконтроллер можно
> отдать распознавание внешнему серверу, а на ESP32 оставить только
> запись и передачу аудио. Текущий скрипт разработан для запуска на ПК.

## Запуск

```bash
python voice_assistant.py
```

После запуска ассистент отобразит зелёным список активационных слов и
будет ожидать, пока вы произнесёте одно из них (например, "горилка").
Сразу после активации прозвучит короткий сигнал и начнётся запись
последующей речи с немедленным выводом текста в консоль. По окончании
фразы дождитесь другого звукового сигнала — он прозвучит после 5 секунд
тишины.

Для остановки программы нажмите `Ctrl+C`.
